## Сценарий демонстрации
1. Войти администратором.
2. Добавить регулярный платёж.
3. Получить напоминание в Telegram.
4. Войти пользователем и отметить оплату.
5. Показать просроченный платёж.
6. Исправить фактическую дату оплаты, просрочка исчезает.
7. Показать следующий период с отдельным статусом.
