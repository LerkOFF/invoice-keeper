# Invoice Keeper

Сервис напоминаний о регулярных платежах: аренда, подписки, серверы и другие периодические расходы.
Кейс хакатона Aeza РнД, уровень Middle.

Администратор вносит платежи, система за 3 дня до срока пишет в Telegram-чат,
команда отмечает оплату в веб-панели. В любой момент видно: что и когда платить,
что уже оплачено и что просрочено.

> Статус: проект в разработке. Ход работ и чек-лист: [docs/PLAN.md](docs/PLAN.md).

## Возможности

- Веб-панель с авторизацией: список платежей с суммой, валютой, сроком, статусом, датой оплаты и просрочкой.
- Две роли: администратор (задаётся в `.env`) и обычный пользователь.
- Регулярные платежи с ежемесячным повторением. У каждого периода своя дата и своя отметка «Оплачено / Не оплачено».
- Telegram-бот: напоминание минимум за 3 дня до срока, без дублей.
- Три валюты (RUB, USD, EUR), итоги считаются отдельно по каждой, без конвертации.
- REST API `/api/v1` с OpenAPI-спецификацией и Swagger на `/api/v1/docs`.

## Быстрый старт

```bash
cp .env.example .env     # заполнить ADMIN_*, TELEGRAM_*, APP_TIMEZONE
docker compose up --build
```

Панель: `http://localhost:8000`, Swagger: `http://localhost:8000/api/v1/docs`.
Вход администратором: `ADMIN_LOGIN` и `ADMIN_PASSWORD` из `.env`, демо-пользователем: `SEED_USER_LOGIN` и `SEED_USER_PASSWORD`.
При первом запуске подгружаются тестовые данные: аренда в рублях, сервер в долларах,
подписка в евро и обычный пользователь из `SEED_USER_LOGIN` / `SEED_USER_PASSWORD`.
Отключить: `SEED_DEMO_DATA=false`. Данные лежат в Docker volume `invoice_data` и переживают перезапуск.

### Telegram-напоминания

1. Создайте бота у `@BotFather`, токен положите в `TELEGRAM_BOT_TOKEN`.
2. Добавьте бота в нужный чат или группу и напишите там любое сообщение.
3. Узнайте id чата: откройте `https://api.telegram.org/bot<TOKEN>/getUpdates`, возьмите `message.chat.id`
   (у групп он отрицательный) и положите в `TELEGRAM_CHAT_ID`.
4. Перезапустите: `docker compose up -d`.

Бот сам проверяет сроки раз в минуту и при старте. Минимум за 3 дня до срока он присылает название, сумму, валюту и дату оплаты,
по одному разу на период. Если платёж добавили позже, напоминание уходит сразу. Оплаченные и удалённые платежи молчат.
Без токена и чата приложение работает, но напоминания не отправляет и пишет об этом в лог.
